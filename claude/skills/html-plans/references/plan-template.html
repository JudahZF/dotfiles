Auth Migration — Implementation Plan

TL;DR Replace the hand-rolled session middleware with library-backed auth in three phases: adapter behind the current interface, dual-write cutover, then removal of legacy code. Zero-downtime; each phase ships independently.

Context

Why this work exists, what breaks if we do nothing, and links to the relevant entry points: src/middleware/session.ts, src/routes/login.ts.

Constraints

  • Existing sessions must survive the cutover.
  • No new runtime dependencies over 50 kB.
